# QA API Testing

Projeto de portfólio de Quality Assurance com foco em testes de APIs REST utilizando Postman.

## Objetivo

Validar respostas de APIs por meio de cenários positivos e negativos, verificando códigos HTTP, estrutura JSON, tipos de dados e regras de negócio.

## Escopo dos testes

- Consulta de produtos por ID
- Listagem de produtos
- Tratamento de recursos inexistentes
- Validação de campos obrigatórios
- Validação de tipos de dados
- Testes de criação, atualização e exclusão simuladas

## Tecnologias

- Postman
- REST API
- JSON
- Git e GitHub

## API utilizada

[DummyJSON](https://dummyjson.com/)

API pública para estudos e testes. Operações de escrita podem ser simuladas e não necessariamente persistem alterações.

## Status do projeto

Em desenvolvimento. Os cenários serão documentados e executados antes da publicação dos resultados.
